2. Array Problems

1. Largest Sum Contiguous Subarray (Kadane’s Algorithm)

Input: [-2, 1, -3, 4, -1, 2, 1, -5, 4] Output: 6 (Subarray: [4, -1, 2, 1])

Approach: Keep a running sum; reset it when it becomes negative. O(n) time, O(1) space.

2. Rotate an Array by K Steps

Input: nums = [1,2,3,4,5,6,7], k = 3 Output: [5,6,7,1,2,3,4]

Approach: Reverse whole array, then reverse first k and remaining n-k. O(n), in-place.

3. Merge Intervals

Input: [[1,3],[2,6],[8,10],[15,18]] Output: [[1,6],[8,10],[15,18]]

Approach: Sort by start, then extend the last merged interval when overlapping. O(n log n).

4. Find the Duplicate Number

Input: [1,3,4,2,2] Output: 2

Approach: Floyd's cycle detection treating values as "next" pointers. O(n) time, O(1) space, no modification.

5. Maximum Product Subarray

Input: [2,3,-2,4] Output: 6

Approach: Track both max and min product ending at each index (a negative can flip them). O(n).

6. Find the Missing and Repeating Number

Input: n = 5, arr = [1, 3, 3, 5, 4] Output: Missing = 2, Repeating = 3

Approach: Mark seen values to find the repeat; use sum formula n(n+1)/2 to derive the missing one. O(n).

7. Subarray with Given Sum

Input: arr = [1,2,3,7,5], sum = 12 Output: [2,4] (1-based indices)

Approach: Sliding window for non-negative numbers; shrink from the left while the window sum exceeds target. O(n).

8. Longest Consecutive Sequence

Input: [100,4,200,1,3,2] Output: 4 (1,2,3,4)

Approach: Put numbers in a Set; only start counting from numbers with no predecessor. O(n).

9. Trapping Rain Water

Input: [0,1,0,2,1,0,1,3,2,1,2,1] Output: 6

Approach: Two pointers with running left/right max; water at a position = min(leftMax, rightMax) - height. O(n), O(1).

10. Next Permutation

Input: [1,2,3] Output: [1,3,2]

Approach: Find first decreasing element from the right (pivot), swap with next larger element to its right, then reverse the suffix. O(n).

3. String Problems

11. Longest Palindromic Substring

Input: "babad" Output: "bab" or "aba"

Approach: Expand around every center (odd and even). O(n²) time, O(1) space.

12. Reverse Words in a String

Input: "the sky is blue" Output: "blue is sky the"

13. Longest Common Prefix

Input: ["flower","flow","flight"] Output: "fl"

14. Group Anagrams

Input: ["eat","tea","tan","ate","nat","bat"] Output: [["bat"],["nat","tan"],["ate","eat","tea"]]

Approach: Use the sorted string (or a 26-letter count) as a hash key. O(n·k log k).

15. Check for Valid Parentheses

Input: "()[]{}" Output: true

16. Implement ATOI

Input: "42" Output: 42

Approach: Skip whitespace, read sign, accumulate digits, clamp to 32-bit signed integer range.

17. String to Integer Conversion

Input: "-123" Output: -123

Approach: Strict conversion — handles optional sign, returns NaN for any invalid character.

18. Longest Repeating Subsequence

Input: "AABEBCDD" Output: "ABD"

Approach: LCS of the string with itself where matching indices must differ (i ≠ j). O(n²).

19. KMP Algorithm for Pattern Searching

Text: "abxabcabcaby", Pattern: "abcaby" Output: 6

Approach: Precompute LPS (longest proper prefix that is also a suffix) to skip re-comparisons. O(n + m).

20. Minimum Window Substring

Input: s = "ADOBECODEBANC", t = "ABC" Output: "BANC"

Approach: Sliding window with a need-count map; expand right until all chars satisfied, then shrink left. O(n).

4. Linked List Problems uses ListNode / fromArray / toArray helpers

21. Reverse a Linked List

Input: 1 -> 2 -> 3 -> 4 -> 5 Output: 5 -> 4 -> 3 -> 2 -> 1

22. Detect and Remove a Loop in a Linked List

Input: Linked List with a loop Output: Loop removed

Approach: Floyd's tortoise-and-hare: detect meeting point, then move one pointer to head; they meet at loop start. Break the link of the node before it.

23. Merge Two Sorted Linked Lists

Input: 1 -> 2 -> 4, 1 -> 3 -> 4 Output: 1 -> 1 -> 2 -> 3 -> 4 -> 4

24. Flatten a Multilevel Doubly Linked List

Input: Nested Linked List Output: Single Flattened List

Approach: Iterative DFS with a stack: push next, then child, so child is processed first. O(n).

25. Find the Intersection Point of Two Linked Lists

Input: A: 4 -> 1 -> 8 -> 4 -> 5, B: 5 -> 0 -> 1 -> 8 -> 4 -> 5 Output: 8

Approach: Two pointers; when one reaches the end, redirect it to the other list's head. Both travel lenA + lenB and meet at the intersection. O(n+m), O(1).

26. Remove N-th Node from the End of the List

Input: 1 -> 2 -> 3 -> 4 -> 5, n = 2 Output: 1 -> 2 -> 3 -> 5

Approach: Move fast pointer n+1 steps ahead, then move both until fast hits null. One pass.

27. Add Two Numbers Represented by Linked Lists

Input: 7 -> 5 -> 9, 8 -> 4 (digits stored in reverse: 957 + 48) Output: 5 -> 0 -> 0 -> 1 (= 1005)

28. Clone a Linked List with Random Pointers

Input: Original List with random pointers Output: Cloned List

Approach: Map original → copy, then wire next/random via the map. O(n) time & space. (An O(1)-space interleaving trick also exists.)

29. Sort a Linked List

Input: 4 -> 2 -> 1 -> 3 Output: 1 -> 2 -> 3 -> 4

Approach: Merge sort — split with slow/fast pointers, sort halves, merge. O(n log n).

30. Check if a Linked List is Palindrome

Input: 1 -> 2 -> 2 -> 1 Output: true

Approach: Find middle, reverse the second half, compare, (optionally restore). O(n), O(1).

5. Stack and Queue Problems

31. Implement Stack Using Queues

Operations: Push, Pop, Top Output: Mimic Stack behavior

Approach: Single queue; after each push, rotate the queue so the new element is at the front. Push O(n), pop/top O(1).

32. Implement Queue Using Stacks

Operations: Enqueue, Dequeue Output: Mimic Queue behavior

Approach: Two stacks (in/out). Move elements from in → out only when out is empty. Amortized O(1).

33. Next Greater Element

Input: [4,5,2,25] Output: [5,25,25,-1]

Approach: Monotonic decreasing stack, iterate from right. O(n).

34. LRU Cache Implementation

Operations: Set, Get Output: Cache results

Approach: JS Map preserves insertion order — delete & re-insert on access to mark as recently used. O(1) per op.

35. Min Stack

Operations: Push, Pop, Top, GetMin Output: Min value of stack

Approach: Auxiliary stack storing the running minimum. All operations O(1).

36. Evaluate Reverse Polish Notation

Input: ["2","1","+","3","*"] Output: 9

37. Circular Queue Implementation

Operations: Enqueue/Dequeue on a fixed-size ring buffer Output: Maintain FIFO order

38. Sliding Window Maximum

Input: nums = [1,3,-1,-3,5,3,6,7], k = 3 Output: [3,3,5,5,6,7]

Approach: Monotonic deque of indices (decreasing values); front is always the window max. O(n).

39. Celebrity Problem

Input: Matrix M where M[i][j] = 1 means i knows j Output: Celebrity index (or -1)

Approach: Elimination — if candidate knows i, candidate can't be celebrity. Verify at the end. O(n).

40. Largest Rectangle in Histogram

Input: [2,1,5,6,2,3] Output: 10

Approach: Monotonic increasing stack of indices; when a shorter bar arrives, pop and compute areas. O(n).

6. Binary Tree and BST Problems uses TreeNode / buildTree helpers

41. Inorder, Preorder, Postorder Traversals

Input: Binary Tree [1,2,3,4,5] Output: Inorder [4,2,5,1,3], Preorder [1,2,4,5,3], Postorder [4,5,2,3,1]

42. Level Order Traversal

Input: [3,9,20,null,null,15,7] Output: [[3],[9,20],[15,7]]

43. Diameter of a Binary Tree

Input: [1,2,3,4,5] Output: 3 (path 4-2-1-3 or 5-2-1-3, counted in edges)

Approach: Post-order DFS returning height; diameter through a node = leftHeight + rightHeight. O(n).

44. Lowest Common Ancestor in a Binary Tree

Input: Binary Tree, Two Nodes Output: Lowest common ancestor

45. Validate a Binary Search Tree

Input: Binary Tree Output: true if it’s a BST

Approach: Pass allowed (min, max) range down the recursion. O(n).

46. Serialize and Deserialize a Binary Tree

Input: Binary Tree Output: Serialized string & reconstructed tree

Approach: Pre-order with '#' markers for null children; rebuild recursively in the same order.

47. Zigzag Level Order Traversal

Input: [3,9,20,null,null,15,7] Output: [[3],[20,9],[15,7]]

48. Kth Smallest Element in a BST

Input: BST [5,3,6,2,4,null,null,1], k = 3 Output: 3

Approach: Iterative inorder traversal (ascending order), stop at the k-th visited node.

49. Maximum Path Sum in a Binary Tree

Input: [-10,9,20,null,null,15,7] Output: 42 (15 + 20 + 7)

Approach: Post-order; each node returns the best downward gain (ignoring negatives) while updating a global max with left + node + right.

50. Construct a Binary Tree from Preorder and Inorder Traversal

Input: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7] Output: Tree [3,9,20,null,null,15,7]

Approach: Preorder gives roots in order; a hash map of inorder indices splits left/right subtrees in O(1). O(n).

7. Graph Problems adjacency list: adj[u] = [v, ...]

1. Breadth-First Search (BFS)

Input: Graph and a starting node Output: BFS traversal

2. Depth-First Search (DFS)

Input: Graph and a starting node Output: DFS traversal

3. Detect Cycle in a Directed Graph

Input: Directed graph Output: true/false if cycle exists

Approach: DFS with 3 colors (white/gray/black). A back-edge to a gray node = cycle.

4. Detect Cycle in an Undirected Graph

Input: Undirected graph Output: true/false if cycle exists

Approach: DFS tracking the parent; a visited neighbour that isn't the parent means a cycle.

5. Dijkstra’s Shortest Path Algorithm

Input: Weighted graph, source node Output: Shortest distances from source

Approach: Min-heap of (dist, node); relax edges lazily. O((V+E) log V). Uses MinHeap helper.

8. Dynamic Programming Problems

1. 0/1 Knapsack Problem

Input: weights = [1,3,4,5], values = [1,4,5,7], capacity = 7 Output: 9

Approach: 1-D DP over capacity iterated backwards so each item is used at most once. O(n·W).

2. Longest Increasing Subsequence

Input: [10,9,2,5,3,7,101,18] Output: 4 (2,3,7,101)

Approach: Patience sorting with binary search — tails[i] = smallest tail of an increasing subsequence of length i+1. O(n log n).

3. Longest Common Subsequence

Input: "abcde", "ace" Output: "ace" (length 3)

4. Edit Distance

Input: "horse", "ros" Output: 3

Approach: dp[i][j] = min operations to convert first i chars of word1 to first j chars of word2 (insert / delete / replace). O(m·n).

5. Partition Equal Subset Sum

Input: [1,5,11,5] Output: true ([1,5,5] and [11])

Approach: Subset-sum DP for target = total/2 using a boolean array. O(n·sum).

9. Searching and Sorting Problems

1. Binary Search

Input: arr = [1, 3, 5, 7, 9], target = 5 Output: 2

2. Merge Sort

Input: [5, 2, 9, 1, 5, 6] Output: [1, 2, 5, 5, 6, 9]

3. Quick Sort

Input: [10, 7, 8, 9, 1, 5] Output: [1, 5, 7, 8, 9, 10]

4. Find First and Last Position of an Element in a Sorted Array

Input: nums = [5,7,7,8,8,10], target = 8 Output: [3,4]

Approach: Two binary searches — lower bound and upper bound. O(log n).

5. Kth Smallest Element

Input: arr = [7, 10, 4, 3, 20, 15], k = 3 Output: 7

Approach: QuickSelect — average O(n). (Alternative: max-heap of size k.)

6. Search in Rotated Sorted Array

Input: nums = [4,5,6,7,0,1,2], target = 0 Output: 4

Approach: Modified binary search: one half is always sorted; check if target lies in it. O(log n).

7. Count Inversions in an Array

Input: [8, 4, 2, 1] Output: 6

Approach: Merge sort; when taking from the right half, every remaining left element forms an inversion. O(n log n).

8. Heap Sort

Input: [12, 11, 13, 5, 6, 7] Output: [5, 6, 7, 11, 12, 13]

9. Counting Sort

Input: [4, 2, 2, 8, 3, 3, 1] Output: [1, 2, 2, 3, 3, 4, 8]

10. Radix Sort

Input: [170, 45, 75, 90, 802, 24, 2, 66] Output: [2, 24, 45, 66, 75, 90, 170, 802]

Approach: Stable counting sort per digit, least significant digit first. O(d·(n + 10)).
